견적서는 Needle · Annual 두 유형으로 나뉘며, 새 견적서 작성 시 선택 카드에서 고릅니다. 모든 데이터는 저장 즉시 서버(DB)에 반영되어 접근 권한이 있는 구성원 모두가 같은 목록을 봅니다.

01

견적서 작성

새 견적서 버튼 → 3단계 선택 → 폼 입력 → 저장

1단계문서 유형 선택

Needle 견적서
음원 사용 곡별 견적서. CD Title / CUE / Publisher | Composer 등 곡 단위 항목 표로 구성됩니다.
OTT · 광고 · 영화
Annual 견적서
연간 블랭킷 라이선스 견적서. 품목 / 규격 / QTY / 단가 / 공급가액 / 부가가치세의 품목형 표로 구성됩니다.
연간 라이선스

2단계카테고리 선택 — OTT / 광고 / 영화

관리·필터용 분류이자, 다음 단계 금액 컬럼 구성의 기본값을 정하는 기준입니다.

3단계합산 대상 선택 — Needle 신규 작성 전용

견적 항목 표의 금액 컬럼 구성을 고르는 단계입니다. 카테고리와 분리되어 있어, 예컨대 광고 견적서에도 영화식 분리 2열을 쓸 수 있습니다.

Domestic & Worldwide
통합 1열 · 수량 + D&W 합산
OTT 기본
금액
단일 금액 1열 · 수량 + 금액 합산
광고 기본
Domestic / Worldwide
분리 2열 · 수량 + 각각 합산
영화 기본

Annual 견적서는 이 단계 없이 바로 폼으로 진입합니다.

폼 입력 — 자동으로 채워지는 것과 직접 입력하는 것

자동 처리
  • 견적서 번호 — YYYY-NNN 연도별 자동 채번 (작성 순서대로, 해마다 001부터)
  • DATE — 오늘 날짜 기본 입력
  • 상태 — 기본값 진행
  • 발신처 정보 — 등록번호 · 상호명 · 대표자 · 소재지 · 업태 · 담당자 기본값 자동 입력
  • TOTAL — 수량 · 금액 입력 시 합계 자동 계산
직접 입력
  • 수신 정보 — 수신처 · 참조 · Tel · Fax · 제목
  • 항목 표 — Needle: CD Title · CD No · CUE · Track No · Publisher | Composer · 단위 · 수량 · 금액 / Annual: 품목 · 규격 · 단위 · QTY · 단가 · 공급가액 · 부가가치세
  • 행 추가 — 곡·품목 수만큼 자유롭게 추가
  • 비고 · 첨부파일 — PDF, Excel 등 관련 파일 첨부 보관
카테고리를 폼에서 바꾸면 합산 대상 컬럼도 그 카테고리의 기본 구성으로 자동 전환되고 항목 표가 새로 시작됩니다. 카테고리와 합산 대상을 먼저 확정한 뒤 항목을 입력하는 것을 권장합니다.

이미 만들어 둔 견적서가 있다면 — 엑셀 업로드

상단 엑셀 업로드 버튼으로 기존 .xlsx 견적서를 올리면 상단 정보와 항목 표를 자동 파싱해 폼에 채워 줍니다. 내용을 확인·수정한 뒤 저장만 하면 되므로, 과거 견적서를 시스템으로 옮길 때 다시 타이핑할 필요가 없습니다.

02

조회와 출력

목록 → 상세 보기 → Excel · PDF

목록 화면

등록된 모든 문서가 한 표에 모입니다. 상단 검색창은 제목 · 수신처 · 견적번호를 한 번에 찾고, 필터 4종을 조합할 수 있습니다.

필터선택지
종류Needle / Annual
유형OTT / 광고 / 영화
상태진행 완료
수신처등록된 수신처 목록에서 선택 · 필터 초기화 버튼으로 일괄 해제

목록 컬럼: NO · 종류 · 번호 · 제목 · 수신처 · DATE · 발행일(세금계산서) · 상태 · 등록일 · 액션(수정/삭제)

상세 보기

목록의 행을 클릭하면 실제 견적서 레이아웃 그대로 읽기 전용 미리보기가 열립니다. 수신·발신 정보, 항목 표, 합계, 비고, 첨부파일까지 출력물과 동일한 모습으로 확인한 뒤 바로 출력하거나 수정으로 넘어갈 수 있습니다.

출력 — 보내는 그 양식 그대로

Excel 내보내기
.xlsx 파일 다운로드. 회사 로고 · 직인 · 대표자 서명란 김  재  경  (인)까지 반영된 완성 양식이라 받은 즉시 거래처로 보낼 수 있습니다.
PDF 인쇄
인쇄 대화상자가 열리며 PDF로 저장을 선택하면 Excel과 동일한 레이아웃의 PDF가 만들어집니다. 카테고리·합산 대상별 컬럼 구성도 그대로 유지됩니다.
03

수정과 관리

수정 · 상태 변경 · 삭제

수정

목록의 연필 아이콘 또는 상세 보기의 수정 버튼으로 진입합니다. 수신 정보, 항목 표, 금액, 비고, 첨부까지 모든 필드를 고칠 수 있고, 저장하면 목록과 상세에 즉시 반영됩니다. 수정 화면에서도 Excel·PDF 출력 버튼을 바로 쓸 수 있습니다.

주의 — 수정 중 문서 유형이나 카테고리를 바꾸면 항목 표가 새 컬럼 구성으로 초기화됩니다. 입력해 둔 곡·품목 내역이 사라지므로, 유형 변경이 필요하면 변경을 먼저 하고 항목을 입력하세요.

상태 관리

견적 진행 단계는 진행 → 완료 두 상태로 관리합니다. 신규 작성 시 자동으로 '진행'이 되고, 계약·정산이 끝난 건은 상세 보기에서 '완료'로 바꾸면 목록 필터로 구분해 볼 수 있습니다.

삭제

목록의 휴지통 아이콘 또는 상세 보기의 삭제 버튼으로 제거합니다. 삭제는 되돌릴 수 없으므로 확인 후 진행합니다.

접근 권한과 데이터

누가 쓰고, 어디에 저장되는가
계정접근 방식
사운드컨텐츠사업부 전원사이드바 · 기능 카탈로그의 '음원 견적 관리'로 바로 진입
김혜진 대리 (회계·경리)동일하게 바로 진입 — 정산 확인용
임종완 주임 · 이광순 이사동일하게 바로 진입
관리자 (mediacube)'견적 관리' 진입 시 음원 / 시스템 선택 모달에서 음원 견적 관리 선택

모든 문서는 사내 데이터베이스(Supabase)에 실시간 저장됩니다. 조회 구조는 데이터가 1,000건을 넘어도 누락·중복 없이 전체를 불러오도록 설계되어 있어, 견적서가 쌓여도 안심하고 사용할 수 있습니다.
