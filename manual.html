Section 01
로그인
로그인 방법
1
아이디 입력
개인 아이디를 입력합니다. (예: developer, soundstore 등)
2
비밀번호 입력
비밀번호를 입력합니다. 입력 후 Enter 키를 눌러도 로그인됩니다.
3
로그인 버튼 클릭
로그인 성공 시 대시보드로 이동합니다. 처음 로그인하면 온보딩 안내 카드가 나타납니다.
💡 로그인 상태는 브라우저에 저장됩니다. 로그아웃하지 않으면 다음 접속 시 자동으로 대시보드로 이동합니다.
📊

🔍
기간 조회
기간 조회 버튼을 클릭하면 날짜 범위 필터 패널이 버튼 위치 기준으로 정확히 열립니다. 오늘 / 이번 주 / 이번 달 / 지난 달 / 최근 3개월 프리셋과 직접 날짜 입력을 모두 지원합니다.
✏️
일지 관리
각 일지 우측의 수정(연필) 버튼으로 수정, 삭제(휴지통) 버튼으로 삭제할 수 있습니다. 상태 · 정렬 · 기간 필터를 조합해 원하는 일지를 빠르게 찾을 수 있습니다.
📋
테이블 / 카드 뷰 전환
목록 우측 상단의 뷰 전환 버튼으로 테이블과 카드 레이아웃을 선택할 수 있습니다.
⭐
즐겨찾기(고정)
일지의 핀 아이콘을 클릭하면 사이드바 즐겨찾기에 등록됩니다. 중요한 일지를 빠르게 다시 찾을 수 있습니다.
+ 새 일지 작성

화면 우측 상단의 + 새 일지 작성 버튼을 클릭하면 오늘 날짜로 업무일지 입력 폼이 열립니다. 이미 오늘 일지가 있으면 해당 일지로 바로 이동합니다.

음원팀 업무 현황 패널

사운드 사업부 계정으로 로그인하면 사이드바에 음원팀 업무 현황 버튼이 표시됩니다. 클릭하면 사운드콘텐츠사업부 팀원 전체의 업무 내역을 슬라이드 패널로 한눈에 확인할 수 있습니다. 같은 팀 내 업무가 서로 겹치지 않도록 조율하고, 팀 전체의 진행 상황을 파악해 협업에 활용하세요.

시스템팀 업무 현황 패널 NEW

시스템 사업부 계정(avsystem · engineer2)으로 로그인하면 사이드바에 시스템팀 업무 현황 버튼이 표시됩니다. 사운드팀과 시스템팀 패널은 부서별로 완전히 분리되어 서로의 데이터가 섞이지 않습니다. 자세한 내용은 19. 시스템팀 업무 현황 섹션을 참고하세요.

사이드바 컴팩트 스페이싱 NEW

사이드바의 여백을 정교하게 조정하여 일반 노트북·데스크탑 해상도에서 메인·상태·바로가기·사업부 보기·관리자 메뉴와 푸터까지 스크롤 없이 한 화면에 들어오도록 정리했습니다.

Section 03
일지 작성
입력 항목 안내
1
주요 목표 (필수)
오늘의 핵심 목표를 입력합니다. 이전에 입력한 내용이 자동완성으로 제안됩니다.
2
업무 유형
개발 · 회의 · 기획 등 업무 성격을 입력합니다. 이전 입력값이 자동완성으로 제안됩니다.
3
금일 업무 내역
오늘 수행한 업무를 한 줄씩 추가합니다. 각 항목마다 시작 시간 / 종료 시간을 입력하면 총 작업 시간이 자동 계산됩니다. 상태(예정·진행중·완료·보류·이슈)와 체크박스로 완료 여부를 표시합니다.
4
업무 추진 현황
업무명, 진행 내용 요약, 진행률(%)을 입력합니다. + 업무 현황 추가 버튼으로 항목을 늘릴 수 있습니다.
5
업무 요약 · 이슈 및 리스크 · 익일 계획
오늘 업무의 전체 요약, 발생한 이슈·리스크, 내일 계획을 각 영역에 자유롭게 입력합니다.
6
저장
하단 저장 버튼을 클릭하면 일지가 저장되고 대시보드로 이동합니다.
동시 진행 업무 & 총 작업시간 계산 NEW
🔀
동시 업무 허용
시간이 겹치는 업무를 동시에 입력할 수 있습니다. (예: 09:00~10:30 회의 + 09:30~10:00 자료 작성)
🧮
Union 합산 계산
겹치는 시간은 한 번만 카운트되어 총 작업시간에 중복 반영되지 않습니다.
점심시간 자동 제외 NEW

업무 시간이 12:30 ~ 13:30 (점심시간)과 겹치는 경우, 해당 구간은 총 작업시간에서 자동으로 제외됩니다.

예시 11:00~14:00 업무 입력 시 → 3시간 중 점심 1시간 제외 → 실 작업시간 2시간
최근 일지 미완료 가져오기 NEW

일지 작성 폼의 금일 업무 내역 영역에서 최근 일지 미완료 가져오기 버튼을 클릭하면, 본인 계정에서 작성일 이전에 작성된 가장 최근 일지의 미완료 업무 항목을 현재 일지로 불러옵니다. (공휴일·휴가로 공백이 있어도 실제 마지막 작성 일지를 기준으로 가져옵니다.)

📥
가져오는 항목
작성일 이전 가장 최근 일지에서 완료 처리되지 않은 업무 항목의 업무명을 가져옵니다.
⏱️
시간 미포함
업무명만 가져오며 시작 시간 / 종료 시간은 복사되지 않습니다. 오늘의 시간은 직접 입력합니다.
💡 지난 일지에서 마무리하지 못한 업무를 빠르게 이어받아 오늘 일지에 추가할 수 있습니다. 버튼은 업무 항목 추가 버튼 옆에 위치합니다.
⚠️ 주요 목표는 필수 입력 항목입니다. 입력하지 않으면 저장되지 않습니다.
🏷️
Section 04
상태 관리
업무 상태 종류

각 업무 항목에 아래 5가지 상태 중 하나를 지정할 수 있습니다.

이슈 진행중 보류 예정 완료
상태 변경 방법

업무 내역 항목의 상태 배지를 클릭하면 드롭다운이 나타납니다. 원하는 상태를 선택하면 즉시 변경됩니다.

일지 전체 상태 자동 결정 우선순위

업무 항목들의 상태를 종합해 일지 전체 상태가 자동으로 결정됩니다.

이슈 › 진행중 › 보류 › 예정 › 완료
예시 업무 5개 중 3개 완료, 1개 진행중, 1개 이슈 → 일지 상태 = 이슈
⚡
Section 05
자동완성 기능
자동완성이 지원되는 필드
  • 주요 목표 — 이전에 입력한 목표 목록 제안
  • 업무 유형 — 이전에 입력한 유형 목록 제안
  • 금일 업무 내역 — 이전에 입력한 업무 내용 제안
  • 업무 추진 현황 · 업무명 — 이전 업무명 제안
  • 업무 추진 현황 · 진행 내용 요약 — 이전 요약 내용 제안
사용 방법
1
필드 클릭 또는 입력
자동완성 지원 필드에 포커스하거나 글자를 입력하면 드롭다운이 자동으로 나타납니다.
2
항목 선택
마우스로 클릭하거나 ↑ ↓ 키로 이동 후 Enter로 선택합니다.
3
항목 삭제
드롭다운 항목에 마우스를 올리면 ✕ 버튼이 나타납니다. 클릭하면 해당 항목이 자동완성 목록에서 영구 제거됩니다.
💡 자동완성 목록은 본인이 작성한 일지에서만 불러옵니다. 다른 계정의 데이터는 표시되지 않습니다.
💹
Section 06
음원 매출 분석 NEW
📌 대시보드 하단 음원 매출 분석 패널에서 월별 음원 매출 현황을 차트와 통계로 한눈에 확인할 수 있습니다. 데이터 입력은 관리자(mediacube), info, developer 계정에서 가능합니다.
월 선택 & 차트 타입
📅
월 선택 드롭다운
음원 매출 분석 패널 좌측 드롭다운으로 조회할 월을 선택합니다. 데이터가 입력된 월만 목록에 표시됩니다.
📊
막대 / 꺾은선 전환
우측 상단 막대 / 꺾은선 버튼으로 차트 타입을 전환합니다. 꺾은선은 항목 간 추이를 비교할 때 유용합니다.
전년도 대비 비교
1
전년도 막대바 자동 표시
전년 동월 데이터가 있으면 연한 색상의 전년도 막대가 현재연도 막대와 나란히 표시됩니다.
2
레전드 체크/해제
차트 우측 상단의 년/월 레전드 칩을 클릭하면 해당 연도를 차트에서 숨기거나 다시 표시할 수 있습니다. ✓ 표시가 체크 상태, ○ 표시가 숨김 상태입니다.
3
전년대비 툴팁
두 연도가 모두 표시된 상태에서 막대 위에 마우스를 올리면 전년대비 증감율(%)이 툴팁에 나타납니다.
통계 패널 — 실매출 / 총매출 상세보기

차트 우측 통계 패널에서 해당 월의 실매출·총매출을 확인하고, 클릭하면 상세 모달이 열립니다.

💰
실 매출 상세
관리자가 직접 입력한 실제 매출 금액. 전년 동월과 비교한 증감율 배지가 함께 표시됩니다.
📋
총 매출 상세
8개 항목(Annual, Needle drop, Buyout 등)의 합산 매출. 각 항목별 금액·비율과 전년 대비 증감을 확인할 수 있습니다.
💡 상세 모달 상단 드롭다운으로 다른 월 데이터를 바로 조회할 수 있습니다. 모달을 닫지 않고도 월을 전환할 수 있습니다.
매출 데이터 입력 (관리자 · info · developer)
1
+ 데이터 입력 버튼 클릭
관리자(mediacube), info, developer 계정으로 로그인 시 우측 상단에 + 데이터 입력 버튼이 나타납니다.
2
년/월 선택 후 항목 입력
8개 항목(Annual, Needle drop, Buyout, Custom/디지털, KOMCA/Koscap, Youtube, 선곡료, 협회 수수료) 금액을 입력합니다.
3
실 매출 직접 입력
하단 실 매출 필드에 실제 정산 매출을 입력합니다. 총 매출은 8개 항목 합산으로 자동 계산됩니다.
4
월별 삭제
월 선택 드롭다운에서 특정 월 옆 ✕ 버튼을 클릭하면 해당 월 데이터가 삭제됩니다.
📈
Section 07
월별 누계 매출 통계 NEW
📌 음원 매출 분석 패널의 월별 누계 통계 버튼을 클릭하면 기간을 선택해 항목별 누적 매출을 차트로 확인할 수 있습니다.
사용 방법
1
기간 선택
시작월과 종료월을 드롭다운으로 선택합니다. 데이터가 있는 월만 목록에 표시됩니다.
2
차트 타입 선택
막대 또는 꺾은선을 선택합니다.
3
조회 버튼 클릭
선택한 기간 내 8개 항목의 누적 합산 금액이 하나의 차트로 표시됩니다.
📊
항목별 누적 차트
X축 = 8개 매출 항목, Y값 = 선택 기간 전체 누적 합산. 각 항목 고유 색상으로 구분됩니다.
💼
통계 패널
기간 내 실매출 합계, 총매출 합계, 항목별 누계 금액과 비율(%)이 우측에 정리됩니다.
🃏
항목별 요약 카드
차트 하단에 8개 항목 각각의 누계 금액이 색상 카드로 표시됩니다.
🔄
즉시 재조회
기간이나 차트 타입을 바꾸고 조회 버튼을 다시 누르면 모달을 닫지 않고 데이터가 즉시 갱신됩니다.
🖨️

Section 09
메신저 (팀 내부 메시지)
📌 대시보드 우측 상단 프로필 아이콘을 클릭하면 메시지 보내기와 메시지 목록 메뉴가 나타납니다. 팀원 간 내부 메시지를 주고받을 수 있습니다. 읽지 않은 메시지가 있으면 빨간 배지가 표시됩니다.
메시지 보내기
1
프로필 클릭 → 메시지 보내기
우측 상단 프로필 아이콘 클릭 후 메시지 보내기를 선택하면 작성 패널이 열립니다.
2
수신자 선택
목록에서 원하는 팀원을 선택합니다. 여러 명에게 동시에 보낼 수 있습니다.
3
내용 작성 & 첨부파일
메시지 내용을 입력합니다. 파일을 첨부할 수 있습니다 최대 10MB · 복수 선택 가능. Ctrl+Enter로 빠르게 전송할 수 있습니다.
4
보내기
보내기 버튼을 클릭하면 메시지가 전송됩니다. 수신자 화면에 팝업 알림이 나타납니다.
메시지 목록 & 관리
📥
수신 메시지 확인
프로필 → 메시지 목록에서 받은 메시지를 확인합니다. 클릭하면 전체 내용과 첨부파일을 볼 수 있습니다.
🗑️
메시지 삭제
메시지 목록에서 체크박스로 선택 후 선택 삭제를 클릭하거나, 전체 선택 후 일괄 삭제할 수 있습니다.
↩️
답장
메시지 상세 보기에서 답장 버튼을 클릭하면 해당 발신자에게 바로 답장 작성 패널이 열립니다.
🔴
읽지 않은 메시지 배지
프로필 아이콘과 메시지 목록 버튼에 빨간 숫자 배지가 표시됩니다. 메시지를 열면 읽음 처리됩니다.
💡 직원 프로필 모달(일지 작성자 클릭)에서도 메시지 보내기 버튼으로 바로 메시지를 보낼 수 있습니다.

메모 / 특이사항
일지에 기록된 특이사항 및 메모를 모아서 보여줍니다. 중요 기록을 빠르게 다시 찾을 수 있습니다.

발생 이슈 NEW
음원팀 전 직원 일지에 기록된 발생 이슈를 모아서 보여줍니다. 이슈 항목마다 이슈 해결 완료 버튼으로 팀 전체에 해결 알림을 발송할 수 있습니다.
검색 & 필터
  • 내용 검색 — 키워드를 입력하면 해당 내용이 포함된 항목만 표시됩니다.
  • 날짜 범위 필터 — 시작일 ~ 종료일을 지정해 특정 기간의 기록만 조회합니다. 초기화 버튼으로 필터를 한 번에 제거할 수 있습니다.
  • 직원 필터 (관리자 전용) — 특정 직원의 히스토리만 따로 볼 수 있습니다.
💡 검색·필터는 실시간으로 적용됩니다. 별도의 조회 버튼 없이 입력하는 즉시 결과가 갱신됩니다.

  • 실 매출 / 총 매출 상세 모달에서 전년 대비 비교 확인
  • 월별 누계 통계 — 기간 선택 후 항목별 누적 차트 조회

Section 13
업무 성과 NEW
📌 사이드바의 업무 성과 메뉴를 클릭하면 일지에 기록된 업무 성과를 기간별로 모아 조회할 수 있습니다. 일지 작성 시 업무 성과 입력란에 작성한 내용이 여기에 표시됩니다.
사용 방법
1
사이드바 → 업무 성과 클릭
우측 슬라이드 패널이 열립니다. 기본값으로 이번 달 1일 ~ 오늘의 성과가 표시됩니다.
2
기간 필터 설정
시작일과 종료일을 입력해 원하는 기간의 성과만 조회합니다. 초기화 버튼으로 전체 기간을 볼 수 있습니다.
3
성과 카드 확인
날짜별로 성과 내용이 카드 형태로 나타납니다. 본인이 작성한 성과는 × 버튼으로 삭제할 수 있습니다.
📝
성과 입력 방법
업무일지 작성 폼의 이슈 및 리스크 섹션 하단 업무 성과 란에 내용을 입력하고 일지를 저장하면 자동으로 성과 목록에 등록됩니다.
👑
관리자 전용: 직원별 조회
관리자(mediacube) 계정에서는 패널 상단 탭으로 직원별 업무 성과를 개별 조회할 수 있습니다.
⚠️
Section 14
발생 이슈 조회 · 해결 알림 NEW
📌 업무 히스토리 패널의 발생 이슈 탭에서 같은 부서 직원의 이슈 기록을 한눈에 조회하고, 이슈 해결 시 부서 전원에게 알림을 발송할 수 있습니다.
부서 단위 격리 NEW

발생 이슈 탭의 가시 범위는 부서 단위로 분리되어 있습니다. 부서가 다른 팀의 이슈는 노출되지 않습니다.

  • 사운드콘텐츠사업부 직원 — 사운드팀 이슈만 조회 가능 (시스템팀 이슈는 비노출)
  • 시스템 사업부 직원 (avsystem · engineer2) — 시스템팀 이슈만 조회 가능 (사운드팀 이슈는 비노출)
  • 관리자(mediacube) · developer — 모든 부서 이슈 가시 (운영·디버깅 목적)
  • 권한 부여(직원별 권한)를 받은 직원 — 허용된 직원의 이슈만 조회
🔔 이슈 해결 알림도 이슈 작성자의 부서 기준으로 전송됩니다. 사운드 이슈는 사운드팀 + 관리자 + developer에게, 시스템 이슈는 시스템팀(avsystem·engineer2) + 관리자 + developer에게 알림이 도달합니다.
발생 이슈 탭 사용 방법
1
사이드바 → 업무 히스토리 → 발생 이슈 탭 클릭
음원팀 전 직원이 일지에 기록한 발생 이슈가 날짜 최신순으로 표시됩니다. 날짜·키워드 필터로 원하는 이슈를 검색할 수 있습니다.
2
이슈 해결 완료 버튼 클릭
이슈가 해결되면 해당 이슈 카드의 이슈 해결 완료 버튼을 클릭합니다. 클릭 즉시 전 직원의 화면에 해결 완료 알림 배너가 표시됩니다.
이슈 해결 완료 알림 배너
✅
실시간 팀 알림
이슈 해결 완료 버튼을 누르면 해당 이슈 내용과 처리자 이름이 담긴 녹색 알림 배너가 팀원 전체 화면 우측 하단에 표시됩니다.
⏱️
10초 유지 · 페이지 이동 후에도 표시
알림 배너는 10초간 표시됩니다. 알림 표시 중 다른 페이지로 이동해도 남은 시간 동안 배너가 계속 표시됩니다.
💡 발생 이슈는 일지 작성 폼의 이슈 및 리스크 섹션에서 입력합니다. 이슈가 입력된 일지는 전체 상태가 자동으로 이슈 로 표시됩니다.
📋
Section 15
업무 지시 NEW
📌 사이드바의 업무 지시 메뉴를 클릭하면 팀원에게 업무를 지시하거나 받은 업무를 관리할 수 있습니다. 지시 발송 시 담당자에게 자동으로 알림이 전송됩니다.
3탭 구성
✏️
업무 지시
새 업무 지시를 작성하는 탭입니다. 제목·상세내용·마감일(선택)·우선순위·담당자를 입력하고 업무 지시하기 버튼을 클릭합니다.
📤
지시한 업무
내가 지시한 업무 목록을 확인합니다. 담당자의 진행 상태가 표시되며, × 버튼으로 삭제할 수 있습니다.
📥
받은 업무
나에게 지시된 업무 목록을 확인합니다. 상태를 변경하고, 일지로 가져오기 버튼으로 오늘 일지에 업무 항목을 추가할 수 있습니다.
업무 지시하기
1
제목·내용·우선순위 입력 (필수)
업무 제목, 상세 내용, 우선순위(높음·중간·낮음)를 입력합니다. 마감일은 선택 사항입니다.
2
담당자 선택 (복수 선택 가능)
담당자 목록에서 체크박스로 1명 이상 선택합니다. 여러 명 선택 시 각자에게 개별 업무 지시가 생성됩니다. 목록은 최대 4명씩 스크롤로 표시됩니다.
3
업무 지시하기 버튼 클릭
전송 즉시 담당자에게 새 업무 지시 도착 알림 배너가 표시되고, 사이드바 업무 지시 버튼에 읽지 않은 수가 뱃지로 나타납니다.
받은 업무 관리
🔄
상태 변경
받은 업무 카드의 상태 드롭다운으로 대기 진행중 완료 중 선택합니다. 변경 즉시 지시자에게 상태 변경 알림이 전송됩니다.
📥
일지로 가져오기
📥 일지로 가져오기 버튼을 클릭하면 해당 업무 항목이 오늘 일지에 자동 추가되고 수정 폼으로 이동합니다. 오늘 일지가 없으면 신규 입력 폼으로 이동합니다.
✅
일지에서 자동 완료 처리
일지에 가져온 업무 항목의 상태를 완료 로 변경하면, 업무 지시 상태도 자동으로 완료로 업데이트되고 지시자에게 완료 알림이 전송됩니다.
🔢
읽지 않은 업무 뱃지
새로운 업무 지시가 도착하면 사이드바 업무 지시 버튼에 빨간 숫자 뱃지가 표시됩니다. 받은 업무 탭을 열면 모두 읽음 처리됩니다.
완료 항목 자동 정리
💡 상태가 완료인 업무는 목록 하단으로 이동되고 회색으로 표시됩니다. 완료 후 24시간이 지나면 자동으로 사라집니다. 지시한 업무 목록에도 동일하게 적용됩니다.
알림 배너 안내
📥
새 업무 지시 도착
업무 지시를 받으면 화면 우측 하단에 새 업무 지시 도착 초록 배너가 10초간 표시됩니다. 다른 페이지로 이동해도 남은 시간 동안 유지됩니다.
🔄
업무 상태 변경 알림
담당자가 상태를 변경하면 지시자에게 업무 상태 변경 노란 배너가 10초간 표시됩니다. 어떤 업무가 어떤 상태로 바뀌었는지 알려줍니다.
⌨️ 업무 지시 패널을 열었을 때 ESC 키를 누르면 패널이 닫힙니다.
🏢

표 보기
6개 항목 × N개 연도 컬럼 + 연도별·항목별 합계가 포함된 표가 표시됩니다. DB에 데이터가 있는 모든 연도를 자동 포함합니다.
연도 선택 · 조회

차트 보기 모드에서 상단의 연도 드롭다운으로 조회할 연도를 선택하고 조회 버튼을 클릭합니다. 기본값은 전년도입니다. 드롭다운에는 DB에 입력된 모든 연도가 자동으로 포함됩니다(과거·미래 모두).

항목별 요약 카드 · YoY 칩
  • 각 항목 카드에 포맷 금액(억원)과 상세 금액(원)이 함께 표시됩니다 (숫자 폭은 tabular-nums로 정렬).
  • 전년 대비 증감률을 색상 칩(▲ 녹색 / ▼ 빨강 / – 변화 없음)으로 표시합니다.
  • 매출이 0이고 전년도도 0인 항목은 카드가 페이드(opacity 0.55) 처리되어 데이터가 있는 항목이 한눈에 들어옵니다.
  • 카드에 마우스를 올리면 살짝 떠오르며 그림자가 진해지는 호버 효과가 적용됩니다.
매출 데이터 입력 (연도별)
1
+ 데이터 입력 버튼 클릭
위젯 우측 상단의 + 데이터 입력 버튼을 클릭하면 연도 단위 입력 모달이 열립니다.
2
연도 선택
기본 범위 현재년 - 5 ~ 현재년 + 1과 DB에 이미 존재하는 모든 연도가 드롭다운에 표시됩니다.
3
+ 연도 추가 NEW
드롭다운에 없는 연도를 입력하려면 + 연도 추가 버튼을 클릭합니다. 프롬프트에 1900~9999 사이 연도를 입력하면 드롭다운에 오름차순으로 삽입되고 자동 선택됩니다. 저장하면 차트 모드·누계 통계 모달 드롭다운에도 즉시 노출됩니다.
4
6개 항목 금액 입력 후 저장
각 항목별 한 해 전체 합계를 천 단위 콤마 자동 포맷으로 입력합니다. 합계는 실시간으로 계산되며 저장 시 해당 연도의 월별 row가 정리되고 단일 연도 row(month_key=YYYY)로 저장됩니다.
2025년 합계 카드

차트 아래 우측에 표시되는 진한 파란 그라데이션 카드. 선택 연도의 전체 매출 합계(억원·원)를 표시하며 KPI 패널과 정확히 동일한 가로 위치·너비로 정렬됩니다.

🔒 시스템 매출 데이터 테이블은 RLS(Row Level Security)로 시스템 사업부 직원과 관리자만 접근 가능합니다. 사운드 사업부 데이터(sales_data)와는 완전히 분리되어 절대 섞이지 않습니다.

시스템 매출 연간 누계 통계 NEW
📌 시스템 매출 분석 위젯의 연간 누계 통계 버튼을 클릭하면 여러 연도의 시스템 매출을 비교 · 누적해 한눈에 분석할 수 있는 모달이 열립니다.
기본 모드
  • 연도 선택 — 시작 연도 ~ 종료 연도 드롭다운으로 기간을 지정합니다. 기본값 시작 = 2021년, 종료 = 현재년.
  • 차트 — X축 = 6개 시스템 매출 항목, 같은 항목 그룹 내에서 선택한 각 연도의 막대가 나란히 표시됩니다.
  • 색상 — 가장 최신 연도는 보라(#7c3aed)로 강조, 이전 연도들은 점점 옅은 회색 톤으로 표시됩니다.
  • 6개 항목 카드 — 차트 X축에 정확히 정렬된 6개 카드로 항목별 누계 금액·점유율·상세금액이 표시됩니다.
  • 총 합계 카드 — 카드 아래 줄 우측에 단일 카드의 2배 폭으로 배치. 라벨·기간 / 큰 금액·상세금액 2단 가로 레이아웃.
전년 대비 모드

모달 상단의 전년 대비 버튼을 클릭하면 각 연도의 막대 옆에 그 전년의 매출이 옅은 점선 막대(borderDash:[4,4])로 함께 표시됩니다.

  • 항목 카드 — 누계 금액 + 전년 대비 증감률(▲/▼ %p) + 점유율 바를 함께 표시
  • 총 합계 카드 — 라벨·기간 | 큰 금액·상세금액 | 전년 동기 + 증감률 3단 가로 레이아웃 (구분선 포함)
💡 전년 대비 모드는 단일 연도뿐 아니라 다년도 비교에서도 작동합니다. 예: 2022~2026 선택 시 2021~2025의 전년 동기 합산이 비교 대상이 됩니다.
차트 정렬

Chart.js의 Y축 너비를 60px로 고정하고 우측 padding을 8px로 설정하여 6개 항목 카드 그리드가 차트의 6개 X축 항목 그룹과 정확히 정렬되도록 설계되어 있습니다. 카드와 막대가 일직선상에 위치해 시각적 비교가 직관적입니다.

Section 20
BMAT 모니터링 통계 NEW
📌 사운드콘텐츠사업부 사이드바의 BMAT 모니터링 통계 메뉴에서 채널별 모니터링 결과(콘텐츠 카운트 · 모집단 · 점유율)를 입력·조회·통계 분석할 수 있습니다. 음원 매출 분석과 무관한 별도 모듈입니다.
데이터 구조
  • 채널 — EBS · KBS1 · KBS2 · SBS · MBC 외 채널을 자유롭게 추가
  • 모니터링 카운트(count_val) — 해당 월 채널에서 모니터링된 콘텐츠 건수
  • 모집단(population) — 해당 채널 전체 모집단 (검사 대상 총량)
  • 점유율 — count_val / population × 100으로 자동 계산
  • 월 단위(month_key='YYYY-MM')로 채널별 row를 별도 테이블(bmat_data)에 저장
주요 기능
📊
월별 채널 차트
선택한 월에 입력된 채널들의 카운트 / 모집단 / 점유율을 막대 또는 꺾은선 차트로 표시합니다.
📈
누계 통계
기간 선택 후 채널별 추이(월별 추이)를 채널 색상별로 나란히 표시합니다. 채널을 선택하면 단일 채널의 월별 추이 차트로 전환됩니다.
⊕
전년 대비 / 전월 대비
누계 통계에서 기본 / YoY / MoM 비교 모드를 토글할 수 있습니다.
✏️
데이터 입력 모달
월 선택 후 채널을 동적으로 추가·삭제하고 각 채널의 카운트·모집단을 입력합니다. 기존 데이터는 자동 pre-fill 됩니다.
🏢 BMAT 모니터링 통계는 사운드 사업부 전용 기능입니다. 시스템 사업부 뷰로 토글하거나 시스템팀 계정으로 로그인하면 BMAT 메뉴·위젯이 자동으로 숨겨집니다.

권한을 부여할 직원(viewer)을 클릭하면 우측에 다른 직원 목록과 체크박스가 표시됩니다.

허용할 직원 체크 후 저장
선택한 viewer가 볼 수 있도록 허용할 직원들을 체크하고 저장하면 employee_permissions 테이블에 row가 upsert됩니다. 본인은 항상 포함되므로 별도 체크 불필요.
영향 받는 화면
  • 일지 목록 · 직원 필터 — 권한 부여된 viewer 계정의 사이드바에 다른 직원 메뉴 노출
  • 업무 히스토리 (익일 계획 / 메모 / 발생 이슈 / 업무 추진현황) — 허용된 직원의 기록만 조회
  • 업무 성과 — 허용된 직원의 성과만 가시
  • 업무 지시 — 담당자 선택 목록에 허용된 직원만 표시
💡 권한 설정은 즉시 적용됩니다. 권한 변경 후 영향을 받는 모든 패널(업무 히스토리·성과 등)은 자동으로 리렌더됩니다.
