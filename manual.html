Section 01
로그인
로그인 방법
1
아이디 입력
개인 아이디를 입력합니다. (예: developer, soundstore 등)
2
비밀번호 입력
비밀번호를 입력합니다. 입력 후 Enter 키를 눌러도 로그인됩니다.
3
로그인 버튼 클릭
로그인 성공 시 대시보드로 이동합니다. 처음 로그인하면 온보딩 안내 카드가 나타납니다.
💡 로그인 상태는 브라우저에 저장됩니다. 로그아웃하지 않으면 다음에 접속 시 자동으로 대시보드로 이동합니다.
📊
Section 02
대시보드
📋
일지 목록
작성된 업무일지가 날짜 역순으로 표시됩니다. 각 항목을 클릭하면 상세 내용을 확인할 수 있습니다.
📈
요약 통계 카드
전체 일지 수, 이번 주 일지 수를 한눈에 확인할 수 있습니다. 카드를 클릭하면 차트 모드가 전환됩니다.
🔍
기간 조회
우측 상단 기간 조회 버튼을 클릭해 특정 날짜 범위의 일지만 필터링해서 볼 수 있습니다.
✏️
일지 관리
각 일지 우측의 수정(연필) 버튼으로 수정, 삭제(휴지통) 버튼으로 삭제할 수 있습니다.
+ 새 일지 작성

화면 우측 상단의 + 새 일지 작성 버튼을 클릭하면 오늘 날짜로 업무일지 입력 폼이 열립니다. 이미 오늘 일지가 있으면 해당 일지로 바로 이동합니다.

📝
Section 03
일지 작성
입력 항목 안내
1
주요 목표
오늘의 핵심 목표를 입력합니다. 이전에 입력한 내용이 자동완성으로 제안됩니다.
2
업무 유형
개발 · 회의 · 기획 등 업무 성격을 입력합니다. 이전 입력값이 자동완성으로 제안됩니다.
3
금일 업무 내역
오늘 수행한 업무를 한 줄씩 추가합니다. 각 항목마다 상태(예정·진행중·완료·보류·이슈)를 설정하고 체크박스로 완료 여부를 표시합니다. + 업무 항목 추가 버튼으로 항목을 늘릴 수 있습니다.
4
업무 추진 현황
업무명, 진행 내용 요약, 진행률(%)을 입력합니다. + 업무 현황 추가 버튼으로 항목을 늘릴 수 있습니다.
5
업무 요약 · 이슈 및 리스크 · 다음 계획
오늘 업무의 전체 요약, 발생한 이슈, 내일 계획을 각 영역에 자유롭게 입력합니다.
6
저장
하단 저장 버튼을 클릭하면 일지가 저장되고 대시보드로 이동합니다.
⚠️ 주요 목표는 필수 입력 항목입니다. 입력하지 않으면 저장이 되지 않습니다.
🏷️
Section 04
상태 관리
업무 상태 종류

각 업무 항목에 아래 5가지 상태 중 하나를 지정할 수 있습니다.

이슈 진행중 보류 예정 완료
상태 변경 방법

업무 내역 항목의 상태 배지를 클릭하면 드롭다운이 나타납니다. 원하는 상태를 선택하면 즉시 변경됩니다.

일지 전체 상태 자동 결정 우선순위

업무 항목들의 상태를 종합해 일지 전체 상태가 자동으로 결정됩니다. 우선순위는 아래와 같습니다.

이슈 › 진행중 › 보류 › 예정 › 완료
예시 업무 5개 중 3개 완료, 1개 진행중, 1개 이슈 → 일지 상태 = 이슈
⚡
Section 05
자동완성 기능
자동완성이 지원되는 필드
  • 주요 목표 — 이전에 입력한 목표 목록 제안
  • 업무 유형 — 이전에 입력한 유형 목록 제안
  • 금일 업무 내역 — 이전에 입력한 업무 내용 제안
  • 업무 추진 현황 · 업무명 — 이전 업무명 제안
  • 업무 추진 현황 · 진행 내용 요약 — 이전 요약 내용 제안
사용 방법
1
필드 클릭 또는 입력
자동완성 지원 필드에 포커스하거나 글자를 입력하면 드롭다운이 자동으로 나타납니다.
2
항목 선택
마우스로 클릭하거나 ↑ ↓ 키로 이동 후 Enter로 선택합니다.
3
항목 삭제
드롭다운 항목에 마우스를 올리면 ✕ 버튼이 나타납니다. 클릭하면 해당 항목이 자동완성 목록에서 영구 제거됩니다.
💡 자동완성 목록은 본인이 작성한 일지에서만 불러옵니다. 다른 계정의 데이터는 표시되지 않습니다.
📈
Section 06
통계 & 차트
📊
월별 작성 추이
월별 작성 건수(막대)와 평균 진행률(꺾은선)을 동시에 보여주는 콤보 차트입니다. 호버 시 수치와 % 가 표시됩니다.
🍩
상태별 분포
이슈 · 진행중 · 보류 · 예정 · 완료 비율을 도넛 차트로 표시합니다.
📅
전체 / 이번 주 전환
상단 통계 카드(전체 일지 / 이번 주)를 클릭하면 차트가 전체 기간 ↔ 이번 주 데이터로 전환됩니다.
📆
월별 리포트
사이드바 월별 리포트 메뉴에서 월 단위로 직원별 업무 추진 현황을 확인할 수 있습니다. (관리자 전용)
🖨️
Section 07
인쇄 / PDF 저장
사용 방법
1
일지 상세보기 또는 입력 폼 열기
대시보드에서 일지를 클릭해 상세보기 페이지로 이동합니다.
2
🖨 인쇄 / PDF 버튼 클릭
우측 상단 인쇄 / PDF 버튼을 클릭하면 브라우저 인쇄 대화상자가 열립니다.
3
PDF로 저장
인쇄 대화상자에서 대상을 PDF로 저장으로 선택하면 업무일지를 PDF 파일로 저장할 수 있습니다.
👑
Section 08
관리자 기능
👑 mediacube 계정으로 로그인 시 관리자 기능이 활성화됩니다.
👁️
전체 일지 조회
모든 직원의 업무일지를 확인할 수 있습니다. 각 일지의 눈 아이콘(👁)을 클릭해 상세 내용을 봅니다.
📊
월별 리포트
사이드바 메뉴에서 직원별 월간 업무 추진 현황과 통계를 확인할 수 있습니다.
👤
직원별 현황
사이드바에서 직원 이름을 클릭해 특정 직원의 일지만 필터링해서 볼 수 있습니다.
🔒
타 직원 일지 수정 불가
관리자는 다른 직원의 일지를 수정할 수 없습니다. 조회(상세보기)만 가능합니다.
👥
